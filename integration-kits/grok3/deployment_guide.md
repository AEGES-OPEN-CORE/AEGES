# Integration-Kit Deployment Boundary

This directory is consumed by the root AEGES demonstration service. The supported public path is documented in [the root deployment notes](../../deployment_guide.md).

```bash
git clone https://github.com/AEGES-OPEN-CORE/AEGES.git
cd AEGES
npm ci
npm start
```

The adapter may use mock output or user-supplied model-provider credentials. Provider output is an analytical signal, not proof of fraud, an enforceable decision, independent validator consensus, or authority to quarantine or release value.

No separate production, Kubernetes, QSAFP service, Redis, PostgreSQL, vault, regulator, exchange, or national-infrastructure deployment is implemented by this folder.

Do not use sensitive or production data.
